# ASTRA: diffusion and flow matching for augmenting rare variable-star classes

CS787 Generative Artificial Intelligence, IIT Kanpur, 2026. Group 4: T Sukumar (231072), Tharun D (231097),
Thamilselvan M (231096).

Classifiers of periodic variable stars do well on common classes and poorly on rare ones. García-Jara et al. (2022)
showed that adding light curves generated by a conditional GAN helps. This project asks whether a DDPM and a
conditional flow-matching model give better synthetic light curves for this purpose than a GAN and a VAE, when all
four are tuned, trained and scored under one protocol. It first replicates the two base papers, then runs a
four-family benchmark on Catalina (five data splits, a memorisation measure next to every score).

**Main result (test balanced accuracy, classifier trained on synthetic curves only, mean of 5 splits):**
flow matching 80.95, DDPM 80.51, GAN 77.02, VAE 73.55, real data only 74.59.

## Layout

| Path | Contents |
|---|---|
| `astra/` | the Python package: data (`catalina.py`, `ztf.py`), the classifier ensemble (`classifier.py`), the replicated GAN (`gan.py`, `run_gan.py`) and PELS-VAE (`pelsvae.py`, `tcn_vae.py`, `run_vae.py`), and the benchmark (`bench_*.py`: data, shared U-Net, the four families, training loop, evaluation, report tables) |
| `build/` | `build_notebooks.py` assembles the notebooks from the cell sources in `build/nb_*/` and the package; tools to read results (`compare_bench.py`, `search_ckpts.py`, `kaggle_log.py`); figure scripts (`data_figs.py`, `final_figs.py`, `length_audit.py`, `report_figs.py`); offline tests (`build/tests/`); the ZTF dataset rebuild (`build/ztf/`) |
| `notebooks/` | the Kaggle notebooks, built from `build/` (do not edit them by hand) |

| Notebook | What it does |
|---|---|
| `ASTRA_00_DATA_audit` | data audit in figures (no GPU) |
| `ASTRA_01_GAN_GarciaJara_replication` | replication of García-Jara et al. (2022), Table 5, on Catalina or ZTF |
| `ASTRA_02_VAE_PELSVAE_replication` | replication of PELS-VAE (Martínez-Palomera et al. 2020) on its OGLE-III release |

## Running

The notebooks are written for Kaggle (2 × T4 GPUs, 12-hour sessions). Each one starts with a `SMOKE` switch for a
short end-to-end check, saves checkpoints, resumes from an attached previous output, and ends with a cell that checks
that every expected result file exists. Configuration is at the top of each notebook (dataset, splits, session hours).

Locally (CPU is enough for the tests and the result tools):

```bash
pip install -r requirements.txt
python build/build_notebooks.py            # rebuild all notebooks from build/ and astra/
python build/tests/test_bench.py <path to catalina_L100.npz> fm
python build/compare_bench.py <folder with the unzipped final outputs> catalina
```

## Data

- Catalina Surveys DR1 periodic variables (Drake et al. 2014): catalogue and photometry from
  http://nesssi.cacr.caltech.edu/DataRelease/ (downloaded and pre-processed by `astra/catalina.py`).
- ZTF light curves from the ALeRCE broker, rebuilt into the paper's format by `build/ztf/` (replication only).
- PELS-VAE's OGLE-III data release on Zenodo (replication only).

## Base papers

- G. García-Jara, P. Protopapas, P. A. Estévez. Improving astronomical time-series classification via data
  augmentation with generative adversarial networks. ApJ 935, 2022 (arXiv:2205.06758).
- J. Martínez-Palomera, J. S. Bloom, E. S. Abrahams. Deep generative modeling of periodic variable stars using
  physical parameters. arXiv:2005.07773, 2020.
